# Contributing Guidelines
Thank you for your interest in contributing to MusikLibre. We aim to provide a welcoming and collaborative environment for everyone, and these guidelines have been written to help keep contributions organised and consistent.

## Table Of Contents
- [About Contributions](#about-contributions)
- [About Issues & Discussions](#about-issues--discussions)

## About Contributions
Before making changes, create a new branch instead of working directly on the default branch. While creating branches please give descriptive titles to them.
### About Pull-Requests
When you are done working on a feature or on a bug, ensure that your code is working as intended. While sending pull-requests write, descriptive titles and descriptive descriptions. In the description, write down the features and issues you have worked on. Once your pull-request has been reviewed and approved, it will be merged.

## About Issues & Discussions
Issues and discussions are two different things but it may sometimes be challenging whether if something is an issue or a discussion.

### Issues
Issues are for **bugs** or other **reproduciable problems***.

Examples may include:
* Songs not being loaded.
* Ads being shown
* App closing randomly

### Discussions
Topics for a discussion are:
* New features to include.
* Removing some old features.
* Changing some features.
